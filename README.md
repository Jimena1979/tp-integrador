# Food Store 🍕

## Descripción del proyecto
Food Store es una aplicación web interactiva desarrollada para la gestión de pedidos de comida. Permite a los usuarios explorar un catálogo, filtrar productos por categoría, buscar ítems específicos y gestionar un carrito de compras personalizado con persistencia de datos.

El proyecto está construido con **TypeScript**, enfocándose en una arquitectura modular, tipado seguro y una experiencia de usuario fluida.

## Características técnicas
- **Persistencia de sesión:** Uso de `localStorage` para mantener el carrito y los datos del usuario.
- **Lógica modular:** Funciones independientes para el manejo de carrito, productos y UI.
- **Tipado robusto:** Uso de interfaces en TypeScript para garantizar la consistencia de los datos.
- **Diseño funcional:** Actualización dinámica de subtotales, totales y contador de artículos.

## Tecnologías utilizadas
- **Lenguaje:** TypeScript
- **Entorno:** Vite
- **Estilos:** CSS3 (Diseño responsivo)

## Instrucciones para ejecutar el proyecto
Debido a que las dependencias se descargan al momento de la instalación, sigue estos pasos:

1. Asegúrate de tener **Node.js** instalado.
2. Clona el repositorio.
3. Abre una terminal en la carpeta raíz del proyecto.
4. Instala las dependencias necesarias: pnpm install
5. Inicia el servidor de desarrollo : pnpm dev
6. La aplicacion se abrira en http://localhost:5173/ desde el login.
